# SmartCare

Automated Health Monitoring and Single-Tap Emergency Response System.

## Project Vision

SmartCare is a web-based healthcare management and emergency
response platform.

## Technology Stack

- Frontend: Next.js, React, TypeScript
- Backend: Node.js, Express, TypeScript
- Database: PostgreSQL
- ORM: Prisma
- Styling: Tailwind CSS, shadcn/ui
- Charts: Recharts

## Project Structure

- apps/web: Frontend application
- apps/api: Backend API
- docs: Documentation
- infrastructure: Deployment and Docker configuration
